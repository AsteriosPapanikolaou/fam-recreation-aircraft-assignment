# Results

This folder contains the committed output snapshot from the FAM solve and the observed-vs-assigned validation.

- `envoy_FAM_assignment_results.csv` contains one assignment record per scheduled flight.
- `envoy_FAM_fleet_distribution.csv` summarizes the assigned fleet mix.
- `envoy_FAM_run_summary.json` records solver status, objective value and consistency checks.

Detailed validation outputs are in [validation/](validation/).
